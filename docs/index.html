Compilação nativa experimental

Clojure, compilado. Sem JVM.

clojure-native transforma um subconjunto documentado de Clojure em executáveis nativos autônomos, usando Rust, Cranelift e um runtime C compacto.

Compilar o primeiro programa Ver código-fonte

  (println "Hello, native."))

Por que existe
( )
A expressividade de Clojure, explorando um caminho inteiramente nativo.
/ 01

Binário autônomo

O objeto gerado pelo Cranelift é linkado ao runtime C embutido. O programa final não depende da JVM para executar.

/ 02

Escopo explícito

Compatibilidade, limites e decisões arquiteturais são documentados como parte do produto — sem prometer uma implementação completa.

/ 03

Runtime enxuto

Valores tagueados, coleções persistentes e GC mark-sweep preciso em um runtime C compacto, single-thread e não móvel.

/ 04

Laboratório aberto

Implementação, testes de conformidade, benchmarks e ADRs vivem no mesmo repositório para tornar a evolução verificável.

Do texto à máquina

Um pipeline pequeno. Cada etapa visível.

A CLI reúne leitura, interpretação e compilação antecipada. No caminho nativo, o código atravessa quatro camadas bem definidas.

01 Entrada

Reader

Transforma o fonte em forms com spans, macros de leitura, Unicode e diagnósticos determinísticos.

02 Semântica

Analyzer

Expande as macros de core suportadas e resolve funções, closures, records, protocolos e controle de fluxo.

03 Código

Cranelift

Emite código de máquina com fast paths nativos para fixnums e acesso direto à shadow stack de roots.

04 Saída

Linker nativo

Combina o objeto gerado com o runtime C e entrega um executável para a plataforma host.

O que já funciona

Mais do que um experimento de “hello world”.

Um recorte crescente da linguagem, acompanhado por testes executáveis e documentação de compatibilidade.

Memória gerenciada

GC preciso com shadow stack de roots

Mark-sweep não móvel e single-thread, com loads e stores de roots emitidos diretamente no código gerado.

Dados imutáveis

Coleções persistentes de verdade

Vetores em trie, mapas e sets híbridos com HAMT, estruturas ordenadas em árvore rubro-negra e operações transientes.

Linguagem

Funções & closures

Ordem superior, aridades fixas, múltiplas e variádicas, recursão, apply e loop/recur.

Abstrações

Protocols & records

defrecord, defprotocol, extend-type e dispatch sobre tipos embutidos.

clojure.core

Core compilado

26 funções, incluindo map, filter, reduce, range, into e comp.

Experimental por design

Este projeto ainda não é um substituto para Clojure/JVM. Interop Java, bignums, sequências lazy, namespaces dinâmicos e projetos multi-arquivo continuam fora do caminho nativo atual.

Comece em minutos

Do clone ao binário nativo.

Compile a CLI em modo release e transforme qualquer exemplo compatível em um executável autônomo para a sua plataforma host.

Rust 1.74+ Cargo Compilador C
terminal 
# 1. Obtenha o projeto
$ git clone https://github.com/EwertonDCSilv/clojure-compiler.git
$ cd clojure-compiler

# 2. Compile a CLI
$ make release

# 3. Gere e execute um binário
$ ./target/release/clojure-native build examples/hello.clj -o hello-native
$ ./hello-native
Hello from native Clojure
