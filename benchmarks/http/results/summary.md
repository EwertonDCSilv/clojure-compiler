# HTTP benchmark — Native vs Clojure/JVM Pedestal

ADR-0013 Gate 6. Generated by `benchmarks/http/run.sh`. Both servers expose the
same minimal route and serve byte-identical responses; only timing differs.

- Response equivalence: **confirmed** (shared body SHA-256 `d9014c4624844aa5…`)
- Repetitions: 5 × 20000 requests
- Route: `GET /greet` → `200 "Hello, world!\n"`
- Environment: AMD Ryzen 5 8600G w/ Radeon 760M Graphics, 12 cores, Java 21.0.9+10-Ubuntu-125.04, Clojure 1.12.5, Pedestal 0.8.2-beta-10 / http-kit 2.8.1

| Metric (median of reps) | Native | Clojure/JVM Pedestal |
| --- | ---: | ---: |
| Throughput (req/s) | 12389 | 6576 |
| Mean latency (µs) | 52.42 | 118.94 |
| p50 latency (µs) | 46.52 | 109.07 |
| p95 latency (µs) | 73.89 | 181.14 |
| p99 latency (µs) | 105.11 | 237.7 |

Native serves **1.884×** the JVM throughput and **2.345×** lower median latency in this environment.

> Engineering measurement, not a universal claim. Compare only within the same
> environment, revision, and toolchain (see benchmarks/README.md).
